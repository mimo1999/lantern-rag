From question to cited answer.

Five handoffs in a fixed order that no request can reorder.

  1. Verify

    A signed token identifies the person, their organization and their roles.

  2. Scope

    A filter is built from that identity, never from anything the browser sends.

  3. Search

    Vector search runs only over the rows the filter allows.

  4. Answer

    The model sees numbered passages and cites them by number.

  5. Record

    The question's hash, the passages used and the timings are logged.

Common questions.

Does any data leave my machine?

Embeddings and answers come from a local Ollama server by default. Nothing goes to a hosted model unless you configure one.

Which files can be uploaded?

PDF, Markdown and plain text, up to 10 MB each. Identical files are detected and indexed once.

Who can add documents?

Organization admins add documents for their own organization. Only platform admins can publish shared documents.

What happens when nothing matches?

The assistant says it found nothing and the model is not called, so no cost and no guessing.

Can one organization see another's audit log?

No. Admins see their own organization's records. Only platform admins can query across organizations.
